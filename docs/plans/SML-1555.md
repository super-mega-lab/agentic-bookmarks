# SML-1555 — anchor_validate resolves shared anchors with file-level isLocal

**Scope:** small · package `server` · Bug

## Problem
`handleAnchorValidate` resolved anchors with the per-file `isLocal` (`matches[0].data.isLocal`, false for shared files), while `handleAnchorListBroken` (`anchor-git.ts:479`) and the extension resolve with hardcoded `isLocal:true`. The flex gate `shouldFlex = enableFlex && (isLocal || enableFlexShared)` therefore dropped flex for shared anchors under the non-default `enableFlexContextShared:false`, so a shared flex-only anchor was `broken` in `anchor_validate` but `warning`/`valid` in `anchor_listBroken` and the UI — defeating the SML-1544 classification parity. Same per-file resolution in `handleAnchorGetRepairPackage`.

## Fix
Split *resolution* `isLocal` from *classification* `isLocal`, mirroring the existing listBroken pattern (`anchor-git.ts:469-501`):
- `handleAnchorValidate` — `resolveAnchors(..., { isLocal: true })`; keep per-file `isLocal` (renamed `fileIsLocal`) for `classifyAnchorStatus` only.
- `handleAnchorGetRepairPackage` — `resolveAnchors(..., { isLocal: true })`; drop the unused `rpIsLocal`.
- `handleAnchorRepair` — **unchanged**. Its `createAnchor` smart-rebuild is *construction*, not resolution; the extension (`anchor-repair-helpers.ts:145,194`) also builds repaired anchors with per-file `isLocal`, so the server already matches. Comment expanded to record why.

Response shapes are unchanged.

## Test
Parity regression in `anchor-repair.test.ts`: a shared flex-only anchor (rigid match fails, windowed flex succeeds — fixture mirrors the SML-1508 listBroken test) under `enableFlexContextShared:false` now resolves (`resolved:true`, `summary.broken:0`), matching the not-broken outcome `anchor_listBroken` already guarantees.

## Decision note
The ticket listed three sites (`:165`, `:288`, `:482`). `:482` was intentionally excluded — maintainer-confirmed it is anchor construction, where per-file `isLocal` is correct (extension parity). Changing it would have *introduced* divergence.
