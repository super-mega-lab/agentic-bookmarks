# SML-1413 — Fix tag anchor regex boundary bug (`\b` → negative lookahead)

## Overview

Tag anchors whose `tagId` ends in `-` fail to resolve because `\b` (word boundary) requires the character before it to be a word char (`[A-Za-z0-9_]`). When tagId ends in `-` (non-word), `\b` never fires regardless of what follows. Replace `\b` with `(?![A-Za-z0-9_-])` — a negative lookahead for the tagId alphabet — at all three call sites.

**Two repos affected:**
- `agentic-bookmarks-core` (primary fix + tests): `/home/marc/sml/agentic-bookmarks-core/`
- `agentic-bookmarks` (extension call sites): `/home/marc/sml/agentic-bookmarks/`

## Approach

Single implementation unit. The change is surgical and identical across all three sites. Define `TAG_TAIL = '(?![A-Za-z0-9_-])'` as a local constant and substitute it for `\b`. Also add `escapeRegex()` wrapping to the two extension call sites that currently interpolate tagId raw.
