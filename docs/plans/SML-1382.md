# SML-1382 — Bookmark Skills via MCP Resources

## Overview

Expose five skill guide resources (`bookmarks://skill/*`) from the MCP server and wire discovery hints into tool descriptions so agents find the right workflow at natural entry points.

**Approach:** Skill content as string constants in `packages/server/src/skills/index.ts`. Existing `handleListResources`/`handleReadResource` in `resource-handlers.ts` extended to serve the four URIs. Tool descriptions in `definitions.ts` get one-line hints at `bookmark_add`, `bookmark_list`, `bookmark_search`. `anchor_getRepairSkillGuide` and all repair tools are left completely untouched.
