# SML-1533: Don't pop the Output panel on every activation (F-022)

`outputChannel.show()` was the unconditional final statement of `activateForWorkspace`, with no dev/log-level gate and no `preserveFocus`. Every folder-bearing window activation popped the "Agentic Bookmarks" Output panel open and stole focus — intrusive, and it read like leftover debugging code.

**Fix:** gate the call behind non-production extension mode and preserve focus:
```ts
if (context.extensionMode !== vscode.ExtensionMode.Production) {
  outputChannel.show(true);
}
```
Production users (the published extension) never get the panel popped; extension developers keep the auto-show convenience without focus theft. Mirrors the existing in-file `extensionMode !== Production` gate and the codebase `show(true)` idiom (the two deliberate show sites both pass `true`). Pure removal was considered but rejected to keep the dev-time convenience.

No unit test: `activate`/`activateForWorkspace` aren't unit-tested (would require mocking the whole vscode activation surface). Covered by typecheck + the full existing suite staying green + build.

**Files:** `packages/extension/src/extension.ts` (one statement gated).
**Scope:** small (1 file).
