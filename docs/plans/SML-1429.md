# Plan: SML-1429 — Welcome page: redesign LEARN section buttons to make external browser navigation explicit

## Overview

The LEARN section renders 4 `<a class="card">` elements that open external browser tabs via `command:vscode.open`. They look identical to in-app navigation buttons, which is jarring for new users.

Fix: replace card tiles with a title + description + explicit "Learn more →" link layout that visually signals external navigation.

## Approach Decision

Replace `<a class="card">` with `<div class="learn-item">` containing:
- Topic title (bold text)
- Description line
- `<a class="learn-link">Learn more →</a>` — styled as a standard underlined blue link (vscode-textLink-foreground)

Rejected alternative: keep tile shape + add ↗ icon. The tile shape is the root of the confusion; keeping it partially mitigates the problem rather than solving it.
