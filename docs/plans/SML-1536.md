# Implementation Plan: SML-1536

## Ticket
**[F-025] `runClear` saves a possibly-dirty non-active document, persisting unrelated unsaved edits**

`runClear`'s third pass strips `@bookmark:<tagId>` comments from each source file. For a file that is not the active editor it does `openTextDocument` → `removeTagComment` (a `WorkspaceEdit`, no save) → unconditional `await doc.save()`. `openTextDocument` returns the existing in-memory document for an already-open tab, so `doc.save()` flushes ALL pending edits in that buffer — silently committing a user's unrelated unsaved edits in a background tab when they run "Clear All" / "Clear File".

## Scope Classification
Small — 2 files in the extension repo (1 source, 1 test). No core changes, no migrations.

## Overview
Sample the document's dirty state **before** the tag-comment edit, and only `save()` when it was clean (and not the active editor). `removeTagComment` always dirties the doc, so the check must come first. When the doc was already dirty, leave the removal unsaved — the same thing the active-editor branch already does.

## Approach Decision
Capture `const wasDirtyBeforeEdit = doc.isDirty;` immediately after resolving `doc` in pass 3, then change the save guard from `if (!isActive)` to `if (!isActive && !wasDirtyBeforeEdit)`. Rejected: detecting open-vs-not and writing the comment removal straight to disk for non-open files — larger, and would duplicate `removeTagComment`'s tag-stripping logic on raw text (divergence risk) for no behavioral gain.

## Files to Modify
- `packages/extension/src/commands/bookmark-crud.ts` — `runClear` pass 3 (tag-comment cleanup): sample `isDirty` before the edit, gate the save.

## New Files
- `packages/extension/src/commands/bookmark-crud-clear-dirty-save.test.ts` — command-handler test (mocks mirror `bookmark-crud-multiroot.test.ts`; `openTextDocument` returns a controllable `{ isDirty, save }`).

## Test Strategy (TDD)
Tag-anchored bookmark in a folder, `activeEditor: null`, drive `agenticBookmarks.clearAll`. RED first:
1. `openTextDocument` returns `{ isDirty: true }` → `save` is NOT called, `removeTagComment` IS called.
2. `{ isDirty: false }` → `save` IS called exactly once.
Existing `bookmark-crud-multiroot.test.ts` and `clear-bookmarks-helpers.test.ts` stay green.

## Invariants to Preserve
Active-editor branch never saves; clean/freshly-opened background docs are still saved (file stays in sync with bookmark data); per-source-file try/catch and 0-based lines unchanged; `removeTagComment` used unchanged.

## Risks & Edge Cases
- `isDirty` must be sampled before the edit (the edit always dirties the doc).
- Active-editor doc may not expose `isDirty` in tests, but that path is gated by `!isActive` and never reads it.
- Tag bookmark whose source is the active editor: behavior unchanged (still not saved).
