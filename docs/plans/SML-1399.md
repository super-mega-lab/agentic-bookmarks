# SML-1399 — Implementation Plan

**Title:** Setting support for hotkey style: chorded, basic, or custom
**Scope:** medium (4 files modified, 0 new files)
**Branch:** SML-1399/hotkey-style-setting
**Design decision (Phase 2):** Custom mode opens VS Code's Keyboard Shortcuts UI pre-filtered; Chorded defaults stay active in Custom mode.

## Overview

Add `agenticBookmarks.hotkeyStyle` enum setting with three values:
- **`chorded`** (default): Current `Ctrl+K Ctrl+B …` chord layer. No behavior change for existing users.
- **`basic`**: Single-press bindings `Ctrl+Alt+K` (toggle), `Ctrl+Alt+L` (next), `Ctrl+Alt+J` (previous) — matching the README's `alefragnani.Bookmarks`-style snippet.
- **`custom`**: Chorded defaults remain active; a new `agenticBookmarks.customizeKeybindings` command opens VS Code's Keyboard Shortcuts UI pre-filtered to our extension.

Both Chorded and Basic bindings ship statically in `contributes.keybindings`. The active set is selected via `when` clauses that read `config.agenticBookmarks.hotkeyStyle`:
- Chorded bindings: `when` extended with `... && config.agenticBookmarks.hotkeyStyle != 'basic'` (active in `chorded` + `custom` + default)
- Basic bindings: `when: "editorTextFocus && config.agenticBookmarks.hotkeyStyle == 'basic'"`
