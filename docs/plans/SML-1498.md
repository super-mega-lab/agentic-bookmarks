# SML-1498: Minor cleanups from SML-1491 review

Two behavior-preserving cleanups from the SML-1491 PR #31 review (findings #6, #7):

- **(a)** `watchers.ts` data-file `onDidDelete` handler does `await refresh()`, but `refresh` is the
  `debounce` wrapper that returns `undefined` — the `await` is a no-op. Drop it (and the now-vestigial
  `async`). Sequencing isn't needed: `invalidateFileCache` is synchronous and already runs first.
- **(b)** `watchers.test.ts` `makeDeps` threads a manual `calls: string[]` array to record call order.
  Replace with `vi.mocked(fn).mock.invocationCallOrder` and remove the array.
