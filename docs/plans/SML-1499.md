# SML-1499 — Fully enforce the revalidate→decorate invariant at the remaining hand-rolled sites

Follow-up to SML-1496 (PR #34). Extension-only, small.

## Problem
SML-1496 centralized the "re-resolve anchors → THEN repaint" order in `createRevalidateAndRepaint`, but three sibling sites in `extension.ts` still hand-rolled `onFileOpened`/`revalidateOpenDocuments` + `updateDecorations`, so a future reorder could silently reintroduce the SML-1491 stale-`!` bug uncaught. `ExtCtx.ops` still exposed the raw trio (dead scaffolding). The helper's repaint was unguarded → a fire-and-forget pulse caller risked an unhandled rejection.

## Decisions
- **Expose `repaintAfter(resolve, context)`** on the helper (the already-private guarded primitive) — the "documented batch variant" for the conditional-resolve (active-editor) and N:1 (init-loop) shapes. The save site routes through the existing `openAndRepaint`.
- **Guard the repaint** inside `repaintAfter` (try/catch + log) so the "never an unhandled rejection" guarantee is total (the watcher pulse invokes it fire-and-forget). The module doc comment records this (supersedes the old "repaint intentionally NOT guarded" note).
- **Delete `ext-context.ts`** — confirmed dead (zero references, no test); removes the ops naming-drift risk at its source.
- **Add a guard tripwire test** (`revalidate-invariant-guard.test.ts`) that fails if a re-resolve is paired with a bare `updateDecorations()` outside the helper in `extension.ts`.

## Changes
- `revalidate-and-repaint.ts`: export `repaintAfter`; guard the repaint; update doc comment.
- `extension.ts`: route init-loop (~847, N:1), active-editor (~1014, conditional), and save (~1025) through the helper.
- delete `ext-context.ts`.
- tests: extend `revalidate-and-repaint.test.ts` (repaintAfter ordering + resolve-guard + repaint-guard); add `revalidate-invariant-guard.test.ts`.

## Acceptance
All re-resolve+repaint sites go through the helper; active-editor & save gain the resolve guard; no raw-trio escape hatch; repaint-guard decision recorded; regression tripwire in place. Verified: `pnpm typecheck`, `pnpm test` (756 pass), `pnpm lint`, `pnpm build` all green.
