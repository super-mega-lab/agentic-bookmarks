# SML-1518 [F-007]: Cursor install clobbers entire mcp.json on a JSON parse error

`applyCursorSetup` did `catch { existing = {}; }` on ANY failure reading/parsing `.cursor/mcp.json`, then unconditionally wrote `{ ...existing, mcpServers: {...} }`. A malformed `mcp.json` (trailing comma, comment, half-edit) was rewritten to contain ONLY `agentic_bookmarks`, dropping every other configured MCP server and sibling top-level key, with no backup. The uninstall path already guards this (refuse-on-malformed, atomic write, one-shot backup); the install path had none of it.

**Verified scope — Cursor only.** The `catch { existing = {} }` clobber pattern appears exactly once in the codebase. Of the three install paths: `applyClaudeSetup` delegates to the `claude mcp add` CLI (never touches JSON itself — immune); `applyCodexSetup` does regex text-replacement on `config.toml` with no `JSON.parse`, so a malformed config is preserved (it only over-writes on a read *failure* of an existing file — far less plausible — and separately lacks the backup/atomic-write hardening, noted as a follow-up). Only `applyCursorSetup` has the catastrophic clobber-on-parse-error bug.

**Fix:** mirror the uninstall guards. New pure, dependency-injected helper `applyCursorInstall` (in `mcp-setup-helpers.ts`, reusing `FsDeps`/suffix constants/`isMissing`/`SERVER_ID` from `mcp-uninstall-helpers.ts`):
- ENOENT/ENOTDIR → first install, proceed with `{}`. Other read errors → rethrow (never clobber).
- Successful read but `JSON.parse` throws, or parsed value is not a plain object → return `{ status: 'malformed' }` and do NOT write.
- Valid existing file → one-shot backup to `<path>.agentic-bookmarks-backup` before mutating.
- Strip legacy server keys, merge `agentic_bookmarks` into `mcpServers`, write atomically (`.tmp` + rename).

`applyCursorSetup` calls the helper; on `malformed` it shows a "left unchanged to avoid clobbering your other servers — fix/remove and re-run" warning and aborts (no `recordMcpInstall`), exactly like `applyCursorUninstall`.

**Files:** `packages/extension/src/commands/mcp-setup-helpers.ts` (new `applyCursorInstall`), `mcp-uninstall-helpers.ts` (export shared `FsDeps`/`isMissing`/`SERVER_ID`/suffix constants), `mcp-config-and-diagnostics.ts` (`applyCursorSetup` routed through the helper), `mcp-setup-cursor.test.ts` (new — malformed-refuse, ENOENT-create, backup-before-write, atomic-rename, legacy-strip, sibling preservation).
**Scope:** small. Codex backup/atomic-write hardening left as a follow-up.
