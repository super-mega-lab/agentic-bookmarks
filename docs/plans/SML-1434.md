# Implementation Plan: SML-1434

## Ticket
**Move HTTP probe out of core, into public extension repo**

`SECURITY.md` in the public `agentic-bookmarks` repo claims "the network layer is published here so you can audit our outbound traffic." Today that claim is false — the only outbound HTTP (the visibility HEAD probe) lives in the private core repo. Moving it to the public extension repo makes the claim accurate, a prerequisite for making the repo public on GitHub.

## Scope Classification
Small — ~9 files across 2 repos (3 in extension, 6 in core)

## Overview
Move `probeRepoVisibility` and its test from core's private `http-probe.ts` into the public extension as `visibility-probe.ts`. Wire the function through `LicensingService.detect()` so it's explicitly passed as `probeFn` in `DetectOptions`. Then remove the function from core, stripping core of all outbound HTTP code.

## Approach Decision

Thread `probeFn` through the `LicensingService.detect()` call directly (Approach A). No interface churn — the new import is internal to LicensingService. This follows the ticket's recommendation ("fewer moving parts") and avoids unnecessary changes to `LicensingServiceDeps`. Existing tests mock `detectWorkspaceVisibility` wholesale, so there's no benefit to making probeFn injectable via deps.
