# SML-1547 — [F-036] Initialize merge discards custom bookmarksDataRoot/registryPath

**Scope:** small (2 source + 1 test). **Package:** server.

## Problem
The Initialize handler's `else` branch in `packages/server/src/index.ts` (the path taken when init meta
already supplied workspaces) reads the registry's `loadedWorkspaceFolders` and, when present, rebuilds
`ctx.workspaces` entirely via `Array.from(currentRoots).map(wr => createWorkspaceInfo(wr))`. Bare
`createWorkspaceInfo(wr)` (core `paths.ts`) defaults `bookmarksDataRoot` → `.bookmarks` and `registryPath` →
`.bookmarks/local/...`, so the custom values `parseWorkspaceConfig` parsed from the real `bookmarks.dataRoot`
setting are dropped for roots that were already present. Every later op (`bookmark_add`/`list`/`delete`,
resource reads, nameIndex self-heal) then targets `.bookmarks` instead of the configured root — bookmarks
appear to vanish.

## Fix
Extract a pure `mergeLoadedWorkspaceFolders(existing, loadedFolders)` into `workspace.ts` (next to
`parseWorkspaceConfig`) and call it from the `else` branch. It seeds a `Map<resolvedRoot, WorkspaceInfo>` from
`existing` (keeping each one's parsed config) and only calls `createWorkspaceInfo(resolved)` for folders not
already present, preserving existing-first order so `ctx.workspaces[0]` is unchanged. Chosen over an inline fix
because the inline handler isn't unit-testable; extraction exposes the logic to `workspace.test.ts`. The first
branch (no init workspaces) is untouched — it legitimately has no custom config to preserve.

## Tests (added to `workspace.test.ts`)
1. Preserves a custom `bookmarksDataRoot`/`registryPath` for a root that is already present and also listed in
   loadedFolders (reproduces the bug).
2. Adds a genuinely-new loaded folder with `createWorkspaceInfo` defaults.
3. Preserves order/identity — `result[0]` is the original primary object.
4. Deduplicates a path-equivalent (trailing-slash) loaded folder to the existing entry.

## Invariants
All other `workspace.ts` exports unchanged; `index.ts` first branch and the `ctx.workspaceRoot` assignment
unchanged; server logs to stderr; 0-based indices. Baseline before work: 891 tests passing.
