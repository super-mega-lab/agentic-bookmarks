# SML-1576: Dirty-buffer anchor repair fix

`applyAutoRepairCandidate` always read target file lines from disk, but `findRepairCandidate` scored the candidate against the live editor buffer. When unsaved edits shift lines, the same index points at different content on disk → silent wrong-line repair.

**Fix:** add optional `fileLines?: string[]` to `applyAutoRepairCandidate`. When provided, skip `fsp.readFile` and use the supplied lines. Thread through `RepairQueueDeps.applyRepair` and the `extension.ts` wiring so all call paths pass buffer lines.

**Files:** `anchor-repair-helpers.ts`, `repairQueue.ts`, `extension.ts` + new `anchor-repair-helpers.test.ts`
