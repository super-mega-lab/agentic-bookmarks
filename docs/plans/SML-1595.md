# SML-1595 — Strengthen sticky edit-tracking tests

Audit remediation (no production code change). Two test files hardened.

## Part A — `stickyGuards.test.ts` (happy-path-only → boundary coverage)
- Pin each `classifyStickyLane` OR-condition at its exact threshold by passing **synthetic `StickyBatchMetrics` objects** (the classifier's input contract), isolating conditions that real inputs naturally couple: `STICKY_BULK_CHANGE_COUNT` (25 not bulk / 26 bulk), `STICKY_BULK_TOUCHED_RATIO` (0.2 / 0.21), `STICKY_BULK_SINGLE_CHANGE_RATIO` (0.3 / 0.31), `hasNearWholeDocumentReplace` flag, and the micro `<=` boundary (2 changes/8 lines micro; 9 lines or 3 changes → medium).
- Metric-computation tests via `summarizeStickyBatch`: `toTouchedRange` insert/remove span + negative-start clamp; `mergeTouchedRanges` adjacency (gap 1 merges, gap 2 splits) + order-independence; `hasNearWholeDocumentReplace` positives + negative guards (`changes.length !== 1`, start not `{0,0}`).
- `lineWithinTouchedRanges` radius boundary (end+1 true, end+2 false, radius 0) and `isExtremeSmartJump` exact threshold (25 false, 26 true, `Math.abs` symmetry).

## Part B — `sticky.test.ts` (over-mocked → real contract + deterministic)
- Replace the hand-written `@agentic-bookmarks/core` mock with `vi.mock(..., async (importOriginal) => ({ ...await importOriginal(), <I/O overrides only> }))`. Only the registry/file-I/O boundary stays faked; `updateAnchorLineCache`, `dispatchByAnchorType`, `classifyAnchorStatus` now run for real (kills the mock-defined-contract that dropped the `nonce` increment; can't drift from core). Chosen over an inline faithful copy because a hand-copied contract is the very anti-pattern being removed.
- Strengthen the per-event snapshot test to assert `lineCache`, `lastUpdatedLine`, and incremented `nonce` from the real function.
- Replace real-timer `settle()` (220ms) with `vi.useFakeTimers()` + `await vi.advanceTimersByTimeAsync(200)` (debounce 150ms) — deterministic, no flake. Intra-event line-shift residual stays intentionally untested.
