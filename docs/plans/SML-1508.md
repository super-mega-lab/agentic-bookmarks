# SML-1508 — anchor_listBroken shared-anchor isLocal parity

**Bug:** `handleAnchorListBroken` (`packages/server/src/tools/anchor-git.ts`) re-resolves
cached entries with `resolveAnchors(..., { isLocal: slot?.isLocal ?? false })`. For shared
bookmarks that's `isLocal:false`, diverging from the extension which always resolves with
`isLocal:true` (`extension.ts:480`). Resolution's only `isLocal` effect is the flex gate
`shouldFlex = enableFlex && (isLocal || enableFlexShared)` (core `anchors.ts:1061`), so under
the non-default `enableFlexContextShared:false` the server marks a flex-only shared anchor
broken while the extension resolves it.

**Fix:** pass `isLocal: true` to `resolveAnchors` (line ~453); keep `slot?.isLocal ?? false`
for `classifyAnchorStatus` (line ~473). One-line change, no public MCP signature change.

**Test:** new regression test in the `handleAnchorListBroken` describe block — a shared,
flex-only-resolvable smart anchor with `registry.settings.anchors.enableFlexContextShared:false`
is now evicted (`summary.broken === 0`); fails pre-fix (`=== 1`), passes post-fix.
