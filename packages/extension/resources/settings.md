# Settings — Help

The **Settings** view surfaces the most useful per-workspace toggles for Agentic Bookmarks in a tree layout, alongside the broader VS Code settings.

Use it to:

- Toggle auto-repair, watchers, note appearance, anchor types, and other commonly tweaked options.
- Reach the full VS Code Settings UI (gear icon in the view title) when you need a property not surfaced here.
- See license / trial status (when applicable).

> Full help content coming in a future release. For the complete settings reference see the configuration section of your VS Code Settings (`Cmd/Ctrl+,` then search "agenticBookmarks").
