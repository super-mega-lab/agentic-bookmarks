# All Bookmarks — Help

The **All Bookmarks** view lists every bookmark across every registered file in the current workspace, grouped by file.

Use it to:

- See the full inventory of bookmarks in one place.
- Jump to a bookmark by clicking its row.
- Filter the list by group (toolbar filter icon) or by free-text search (right-click → Add Search Filter).
- Sort by user-defined order, by file/line, or by most recent edit (change via **Bookmarks: Set Sort Mode (All Bookmarks)…** from the command palette).
