# Files &amp; Groups — Help

The **Files + Groups** view shows the structural layout of your bookmarks: which files are registered, which groups belong to each file, and which bookmarks belong to each group.

Use it to:

- Register a new bookmarks file (toolbar "+" icon).
- Create groups, rename them, reassign them between files, and reorder by drag-and-drop.
- Toggle group visibility and focus.
- Set per-file anchor type defaults and local/shared mode.

> Full help content coming in a future release. For an overview of local vs. shared bookmarks and groups, see the [Getting Started Guide](command:agenticBookmarks.openGettingStarted).
